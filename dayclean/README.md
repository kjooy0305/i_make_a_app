# 하루 정리

아침 정리, 기록, 저녁 정리, 회고로 하루를 돌리는 흑백 기록 앱입니다.

## 하루 흐름

1. **아침 정리**(기본 07:00): 어제 넘긴 기록과 오늘 '-' 기록을 확인하고 오늘 할 일을 추가한 뒤 장기 목표를 점검합니다.
2. **기록**: 홈의 기록장에 •(지금 당장), -(오늘 안에), =(메모)를 나눠 적습니다.
3. **저녁 정리**(기본 19:00): 남은 기록을 체크만 할 수 있습니다. 확인을 눌러야 끝납니다.
4. **회고**(기본 22:00): 못한 일을 내일로 넘기거나 끝내고, 내일 할 일을 미리 적습니다.

정리 시간이 되면 알림이 울리고, 앱을 열면 홈 대신 그 정리 화면이 바로 열립니다. 정리 시간은 설정에서 바꾸거나 추가할 수 있고, 기본 세 개는 지울 수 없습니다.

## 알림

- •는 쓰고 10분 뒤부터, -는 고른 정리 시간부터 10분마다, 항목마다 따로 울립니다. 알림의 [완료]는 그 항목만 처리합니다.
- 메모는 알림이 없고 저녁 정리에도 나오지 않습니다.
- 알림 쉬는 시간(여러 구간, 요일별)에는 반복 알림이 쉬고, 끝나면 남은 항목을 한 번 알립니다.
- 정확한 알람과 부팅 후 복구를 써서 앱이 꺼져 있어도 울립니다. 설정에서 앱을 강제 종료하면 다시 열기 전까지 울리지 않습니다.

## 기록과 메모리

- 00시에 그날 기록이 메모리(날짜 → 미룬 것 / 메모 / 해결한 내용)로 옮겨집니다. 넘기기로 한 것만 다음 날 연노랑으로 나옵니다.
- 장기 목표도 메모리에 D-n으로 남습니다. 한 달 넘게 남았을 땐 한 달마다(D-92, D-61, D-31), 한 달 이내엔 1주일마다(D-28 … D-7, D-DAY), 목표일이 지나면 해결할 때까지 매일(D+1, D+2 …). 해결하면(기록장의 목표 항목 체크 또는 점검의 [달성]) 그날 **작성 날짜·시간 / 해결 날짜·시간 / 작성 후 걸린 시간** 3줄이 남고, 해결 목록에는 ‘그날 쓰고 끝낸 것’으로 올라가지 않습니다. 앱을 열지 않은 날(최대 60일)도 자정 이관 때 빠짐없이 기록합니다.
- 메모리는 날짜나 내용으로 검색하고, 오늘 · 전체 기록을 txt로 내보내고 불러옵니다.
- **메모리 리셋**: 메모리 화면의 [메모리 리셋 (날짜까지 지우기)]에서 날짜를 고르면 그날까지(포함)의 날짜별 기록만 지웁니다. 몇 일 · 몇 건이 지워지는지 먼저 보여 주고 [지우기]/[취소]로 확인합니다. 기록장, 진행 중인 장기 목표, 설정은 그대로이고 되돌릴 수 없으니 필요하면 먼저 [전체 내보내기]로 백업하세요.

## 장기 목표

1주 · 1달 · 1년 목표를 쓰고 D-day로 봅니다. 목표 날짜는 주기로 자동 계산(1주 = +7일, 1달 = 같은 날짜·말일이면 다음 달 말일, 1년 = 같은 날짜)하거나 직접 입력하고 달력에서도 고를 수 있습니다.
목표는 **장기 목표 점검 화면의 [달성]** 또는 **목표 수정 화면의 [이 목표 해결]** 로 해결하며, 어느 쪽이든 “정말 해결했나요?” 확인 창에서 [해결했어요]를 눌러야 처리됩니다([취소]하면 그대로).
점검은 아침 정리 뒤에 1주는 매일, 1달은 7일마다, 1년은 매달 1일에 나옵니다. 종류별로 끄거나 전체를 끌 수 있고, 10일 남은 목표의 기록장 자동 추가도 따로 끌 수 있습니다.

## 구조

| 폴더 | 내용 |
|---|---|
| `model/` | 기록, 목표, 설정, 메모리 모델 |
| `logic/` | 자정 이관(`Rollover`), 알림 계산(`Reminders`, `Rests`, `Engine`), 정리 화면 판단(`Gate`), 장기 목표 점검(`GoalReview`), 날짜 규칙(`Dates`), 변경 동작(`Ops`), txt 형식(`MemoryText`), 검색 |
| `data/` | JSON 저장(`Store`, `StateJson`) |
| `platform/` | 알림, 정확한 알람, 수신기 |
| `ui/` | 화면. 모두 흑백 · 연노랑 |
| `mock/` | 화면 시안(웹) |

## 테스트

```
./gradlew testDebugUnitTest
```

`LogicTest`는 날짜 규칙, 알림 시각, 자정 이관, 정리 화면 순서, 점검 일정, txt 왕복, 검색을 확인합니다. `UiTest`는 Robolectric으로 화면 이동과 조작, 알림 발송, [완료] 버튼을 확인합니다.
