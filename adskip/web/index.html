광고 건너뛰기

유튜브 광고가 뜨면 ‘건너뛰기’를 대신 눌러 주는 도구 · 폰 앱 + 컴퓨터 확장 프로그램

📱 폰용 APK · 💻 확장 프로그램 내려받기 🐒 유저스크립트 (Tampermonkey용)

전부 화면 안에서만 동작하고 어디에도 데이터를 보내지 않습니다. 인터넷 권한도 없습니다. 개인용으로만 쓰세요.

어떻게 되는 거야? (원리)

튜브캐시 같은 앱이 광고를 ‘자동 스킵’하는 건 마법이 아니라, 안드로이드 접근성 서비스라는 기능을 쓰는 겁니다. 시각장애인용 화면 읽기(TalkBack)에 쓰는 바로 그 기능인데, 이게 세 가지를 할 수 있어요.

① 화면 변화 알림 받기유튜브 화면이 바뀔 때마다 시스템이 “바뀌었어”라고 알려 줍니다(접근성 이벤트).
② 화면의 버튼·글자 읽기화면에 보이는 모든 버튼·글자를 나무(트리) 구조로 읽습니다. 유튜브 건너뛰기 버튼은 아이디가 skip_ad_button, 글자가 ‘광고 건너뛰기’예요.
③ 대신 누르기찾은 버튼에 ‘클릭’ 동작을 보냅니다. 거절당하면 버튼 좌표를 손가락처럼 탭합니다.

튜브캐시 앱(com.yourtube.cash)을 뜯어 보면 YtService라는 접근성 서비스가 있고, 정확히 이 순서로 동작합니다.

  • 유튜브 앱의 창 변화·내용 변화 이벤트만 받습니다 (TYPE_WINDOW_CONTENT_CHANGED 등).
  • 버튼 아이디 4종(skip_ad_button, skip_ad_text, skip_button, player_skip_ad_button)을 먼저 찾고, 없으면 글자(“광고 건너뛰기”, “건너뛰기”, “Skip ads”, “Skip Ad”, “Skip”)로 찾습니다.
  • 보이는 버튼을 찾으면 클릭 가능한 조상까지 올라가 ACTION_CLICK, 실패하면 버튼 가운데 좌표에 80ms 탭 제스처를 보냅니다. 같은 버튼은 0.8초 안에 두 번 안 누릅니다.
  • 버튼이 켜지는 순간을 놓치지 않도록 이벤트 뒤에 몇 번 더 살펴봅니다.

여기서 만든 폰 앱은 이 방식을 그대로 옮긴 것이고(캐시 적립·광고 SDK 없이 스킵 기능만), 컴퓨터용은 같은 생각을 웹에 옮긴 것입니다. 브라우저에서는 접근성 트리 대신 HTML DOM 을 읽을 수 있어 더 많이 할 수 있어요.

  • 유튜브 플레이어는 광고 중에 ad-showing 클래스를 붙입니다. 그걸 신호로 삼습니다.
  • ‘건너뛰기’ 버튼(.ytp-skip-ad-button 등)이 보이면 누릅니다.
  • 버튼이 아직 없거나 건너뛸 수 없는 광고는 광고 <video>의 재생 위치를 끝으로 보내 바로 끝냅니다. 광고 중엔 잠깐 음소거했다가 되돌립니다.
  • 배너·추천 광고 칸은 CSS 로 숨깁니다.

📱 폰 (안드로이드)

설치

  1. 릴리즈 페이지에서 AdSkip-v1.0.0.apk 내려받아 설치 (알 수 없는 앱 허용 필요).
  2. 앱을 열고 [접근성 설정 열기] → 목록에서 ‘광고 건너뛰기 (자동 클릭)’ 켜기.
  3. 안드로이드 13 이상에서 “제한된 설정”이라며 못 켜게 하면: 설정 › 애플리케이션 › 광고 건너뛰기 › 오른쪽 위 ⋮ › 제한된 설정 허용 을 누른 뒤 다시 켭니다. (앱 안의 [앱 정보 열기] 버튼으로 바로 갑니다.)
  4. 유튜브 앱을 열면 끝. 광고 건너뛰기 버튼이 뜨는 순간 자동으로 눌립니다.

설정

  • 브라우저에서 보는 유튜브: 크롬·삼성 인터넷·엣지·파이어폭스·웨일·네이버 앱에서 m.youtube.com 을 볼 때도 글자로 버튼을 찾아 누릅니다.
  • 건너뛸 때 작게 알려 주기: 화면 아래 “광고 건너뜀 (n회)” 표시.
  • 건너뛴 횟수와 최근 기록(시각·방법)이 앱 화면에 쌓입니다.

접근성 서비스는 화면 내용을 읽을 수 있는 강력한 권한입니다. 이 앱은 인터넷 권한이 없어 밖으로 보낼 길 자체가 없고, 소스는 여기에 다 있습니다. 배터리 최적화에서 이 앱을 제외하면 더 안정적으로 돕니다.

💻 컴퓨터 (크롬 · 엣지 · 웨일 · 브레이브 · 파이어폭스)

크롬 계열 (크롬·엣지·웨일·브레이브)

  1. 릴리즈 페이지에서 AdSkip-extension-v1.0.0.zip 내려받아 압축 풀기.
  2. 주소창에 chrome://extensions (엣지는 edge://extensions, 웨일은 whale://extensions) 입력.
  3. 오른쪽 위 개발자 모드 켜기 → 압축해제된 확장 프로그램을 로드합니다 → 압축 푼 폴더 선택.
  4. 유튜브를 열면 끝. 툴바 아이콘을 누르면 건너뛴 횟수와 설정이 나옵니다.

파이어폭스

가장 간단한 방법은 아래 유저스크립트입니다(영구). 확장으로 쓰려면 about:debugging#/runtime/this-firefox → 임시 부가 기능 로드 → zip 안의 manifest.json 선택 (브라우저를 닫으면 풀립니다).

유저스크립트 (어느 브라우저든, Tampermonkey / Violentmonkey)

  1. Tampermonkey 또는 Violentmonkey 설치.
  2. adskip.user.js 를 열면 설치 창이 뜹니다 → 설치.

📱 폰 브라우저에서 유튜브를 볼 때

  • 안드로이드 파이어폭스: 부가 기능에서 Tampermonkey(또는 Violentmonkey) 설치 → 위 유저스크립트 링크 열어 설치. 광고 영상 자체를 끝으로 보내므로 앱 방식보다 빠릅니다.
  • Kiwi 브라우저 등 확장을 지원하는 브라우저: 컴퓨터와 같은 방법으로 zip 확장 로드.
  • 크롬·삼성 인터넷: 확장을 못 깔지만, 위 폰 앱에서 ‘브라우저에서 보는 유튜브’를 켜면 버튼을 대신 눌러 줍니다.
  • 아이폰: 접근성 서비스 같은 기능이 없어 앱 방식은 불가능. Safari 용 유저스크립트 앱(Userscripts)에 위 스크립트를 넣으면 브라우저 안에서는 됩니다.

주의

  • 유튜브가 버튼 아이디·클래스 이름을 바꾸면 못 찾을 수 있습니다. 그땐 목록에 이름을 추가하면 됩니다 (SkipMatcher.kt, content.js 맨 위).
  • 광고를 건너뛰는 건 유튜브 약관과 맞지 않을 수 있습니다. 개인 기기에서 개인용으로만 쓰세요.
  • 접근성 서비스는 가끔 시스템이 끕니다(앱 업데이트·배터리 최적화). 앱을 열면 켜짐/꺼짐이 바로 보입니다.
