# EpubMaker — EPUB 편집기

> 스마트폰에서 직접 EPUB 전자책을 만들고 편집할 수 있는 안드로이드 앱입니다.

---

## 앱 기능

- EPUB 파일 새로 만들기 / 기존 파일 편집
- 챕터별 내용 작성
- 글꼴 선택 및 커스텀 폰트 추가
- 굵게 · 기울임 · 밑줄 · 정렬(왼쪽/가운데/양쪽)
- 글 사이에 이미지 삽입
- 목차 자동 생성

---

## 설치 방법 (APK 직접 설치)

> 구글 플레이스토어 없이 APK 파일을 직접 설치하는 방법입니다.
> 아래 순서대로 따라 하시면 누구나 설치할 수 있습니다.

---

### 1단계 — APK 파일 다운로드

**스마트폰으로 바로 다운로드하는 경우 (가장 쉬움)**

1. 스마트폰의 인터넷 브라우저(크롬 등)를 엽니다.
2. 주소창에 아래 주소를 입력하고 이동합니다.

   ```
   https://github.com/kjooy0305/maybeitok/releases/latest
   ```

3. 페이지 아래쪽 **Assets** 항목을 찾아서 탭합니다.
4. `EpubMaker-xxxxxxx.apk` 파일을 탭하여 다운로드합니다.

> 파일 이름에서 `xxxxxxx` 부분은 버전 번호입니다. 아무거나 탭하면 됩니다.

---

**PC로 다운로드한 뒤 스마트폰으로 옮기는 경우**

1. PC 브라우저에서 아래 주소로 이동합니다.

   ```
   https://github.com/kjooy0305/maybeitok/releases/latest
   ```

2. 페이지 아래쪽 **Assets**를 클릭합니다.
3. `EpubMaker-xxxxxxx.apk` 파일을 클릭하여 다운로드합니다.
4. 다운로드된 APK 파일을 USB 케이블 또는 카카오톡(나에게 보내기)으로 스마트폰에 전송합니다.

---

### 2단계 — 알 수 없는 앱 설치 허용

> 구글 플레이스토어를 거치지 않은 앱을 설치하려면 이 설정이 필요합니다.
> 안드로이드 버전에 따라 방법이 조금 다릅니다.

**안드로이드 8.0 이상 (대부분의 최신 폰)**

1. 스마트폰의 **설정** 앱을 엽니다.
2. **앱** 또는 **애플리케이션**을 탭합니다.
3. 오른쪽 상단 점 세 개(⋮) 메뉴 → **특별한 앱 접근** 또는 **특수 앱 액세스**를 탭합니다.
4. **알 수 없는 출처의 앱 설치**를 탭합니다.
5. 사용 중인 브라우저(예: Chrome) 또는 파일 관리자를 찾아 **허용**으로 켭니다.

> 삼성 갤럭시 기준: 설정 → 생체 인식 및 보안 → 출처를 알 수 없는 앱 설치

**안드로이드 7.0 이하 (구형 폰)**

1. **설정** → **보안** → **알 수 없는 출처** 를 켭니다.

---

### 3단계 — APK 파일 설치

1. 스마트폰의 **파일 관리자** 앱을 엽니다.
   - 삼성: 내 파일
   - LG: 파일 관리자
   - 기타: 파일 앱
2. **다운로드** 폴더로 이동합니다.
3. `EpubMaker-xxxxxxx.apk` 파일을 탭합니다.
4. **설치** 버튼을 탭합니다.
5. 설치가 완료되면 **열기**를 탭합니다.

---

### 4단계 — 앱 실행

- 홈 화면 또는 앱 서랍에서 **EpubMaker** 아이콘을 찾아 탭합니다.
- 앱이 실행되면 바로 사용할 수 있습니다.

---

## 자주 묻는 질문

**Q. "이 앱이 기기에 해를 끼칠 수 있습니다"라는 경고가 뜨는데요?**

A. 구글 플레이스토어를 거치지 않은 앱은 이런 경고가 뜨는 것이 정상입니다.
**그래도 설치** 또는 **허용**을 탭하면 됩니다.

---

**Q. 설치했는데 앱이 실행되지 않아요.**

A. 안드로이드 8.0(오레오) 이상이 필요합니다.
설정 → 휴대전화 정보 → 안드로이드 버전에서 확인할 수 있습니다.

---

**Q. 새 버전은 어떻게 받나요?**

A. 위의 설치 방법과 동일하게 다시 다운로드하여 설치하면 됩니다.
기존 데이터는 유지됩니다.
