EpubMaker 사용 설명서

📖 앱 소개

EpubMaker는 EPUB 3.0 형식의 전자책을 만들고 읽을 수 있는 앱입니다. 편집기와 뷰어 두 가지 모드로 동작합니다.

🏠 홈 화면

모드 선택

상단 탭에서 편집기 또는 뷰어를 선택합니다.

  • 편집기 모드: 파일을 탭하면 편집 화면이 열립니다.
  • 뷰어 모드: 파일을 탭하면 읽기 화면이 열립니다.

파일 관리

  • + 버튼: 새 EPUB 만들기
  • ↑ 버튼: 기존 EPUB 파일 불러오기
  • 파일 길게 누르기: 삭제 메뉴

설정

  • 언어: 메뉴 → 언어에서 한국어/English 전환
  • 설명서: 메뉴 → 설명서에서 이 페이지 열기

✏️ 편집기

기본 서식

  • B : 굵게 (선택한 텍스트에 적용)
  • I : 기울임
  • U : 밑줄
  • ≡L / ≡C / ≡R : 왼쪽 / 가운데 / 오른쪽 정렬

글꼴 · 글자 크기

  • 하단 바 글꼴 버튼: 편집기 전체 기본 글꼴 설정 (저장 파일에는 포함되지 않음)
  • 서식 바 크기 버튼: 선택한 텍스트의 크기 변경 (저장 파일에 포함됨)

챕터 관리

  • 왼쪽 상단 햄버거 메뉴: 챕터 목록 열기
  • 챕터 검색 → 목록 위 검색창에 입력
  • 챕터 이름 길게 누르기 → 이름 변경
  • 하단 이전 챕터 / 다음 챕터: 챕터 이동
  • 하단 챕터 추가 / 챕터 삭제

이미지

  • 하단 이미지 삽입: 갤러리에서 이미지 선택
  • 하단 이미지 목록: 전체 이미지 보기 / 이미지 위치로 이동
  • 이미지 길게 누르기: 보기 / 다운로드 / 복사 / 잘라내기 / 삭제

저장

  • 하단 저장: EPUB 파일로 저장 (Downloads/EpubMaker 폴더)
  • 하단 임시저장: 현재 내용 임시 보관

👁️ 뷰어

챕터 이동

  • 하단 이전 챕터 / 다음 챕터 버튼
  • 메뉴 → 챕터 목록에서 바로 이동

검색

  • 상단 돋보기 아이콘 또는 메뉴 → 검색
  • 현재 챕터 검색: 해당 챕터 내에서만 검색
  • 전체 챕터 검색: 모든 챕터에서 검색, ▲▼으로 다음 결과 이동

책갈피

  • 메뉴 → 책갈피: 현재 위치에 책갈피 추가
  • 메뉴 → 책갈피 목록: 저장된 책갈피 목록 / 탭하면 해당 위치로 이동

뷰어 설정 (메뉴 → 뷰어 설정)

  • 페이지 넘김 방식:
    • 스크롤: 자유 스크롤, 하단 버튼으로 챕터 이동
    • 좌우 터치: 화면 좌/우 탭으로 챕터 이동
    • 상하 터치: 화면 상/하 탭으로 챕터 이동
    • 좌우 스와이프: 화면을 좌우로 밀어 챕터 이동
    • 상하 스와이프: 화면을 상하로 밀어 챕터 이동
  • 방향 반전: 터치/스와이프 방향 반전
  • 글자 크기: 슬라이더로 조절 (12–44px)
  • 이미지 잘림 방지: 이미지가 화면 밖으로 나가지 않게 조절
  • 배경 색상 / 글자 색상: 색상 팔레트에서 선택

이미지 목록

  • 메뉴 → 이미지 목록: 책의 모든 이미지 표시
  • 이미지 탭: 해당 챕터로 이동
💡 팁: 좌우 터치 모드에서 화면 가운데 영역을 탭하면 챕터 이동이 없어 세부 내용을 확인하기 좋습니다.
