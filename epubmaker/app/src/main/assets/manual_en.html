EpubMaker User Manual

📖 Overview

EpubMaker lets you create and read EPUB 3.0 e-books. It has two modes: Editor and Viewer.

🏠 Home Screen

Mode Selection

Use the tabs at the top to switch between Editor and Viewer mode.

  • Editor mode: Tap a file to open the editing screen.
  • Viewer mode: Tap a file to open the reading screen.

File Management

  • + button: Create a new EPUB
  • ↑ button: Import an existing EPUB file
  • Long press a file: Delete menu

Settings

  • Language: Menu → Language to switch Korean/English
  • Manual: Menu → Manual to open this page

✏️ Editor

Basic Formatting

  • B: Bold (applied to selected text)
  • I: Italic
  • U: Underline
  • ≡L / ≡C / ≡R: Left / Center / Right align

Font & Font Size

  • Bottom bar Font button: Sets editor-wide default font (not saved in file)
  • Toolbar Size button: Changes size of selected text (saved in file)

Chapter Management

  • Hamburger icon (top-left): Open chapter list
  • Chapter search → type in the search box above the list
  • Long press a chapter → Rename
  • Bottom Prev Chapter / Next Chapter: Navigate chapters
  • Bottom Add Chapter / Delete Chapter

Images

  • Bottom Insert Image: Select from gallery
  • Bottom Image Gallery: View all images / navigate to image location
  • Long press an image: View / Download / Copy / Cut / Delete

Saving

  • Bottom Save: Export as EPUB file (Downloads/EpubMaker folder)
  • Bottom Auto-save: Temporarily save current content

👁️ Viewer

Chapter Navigation

  • Bottom Prev Chapter / Next Chapter buttons
  • Menu → Chapters: Jump directly to any chapter

Search

  • Magnifier icon or Menu → Search
  • Current chapter: search within the current chapter only
  • All chapters: search across all chapters, use ▲▼ to jump between results

Bookmarks

  • Menu → Bookmark: Add a bookmark at the current position
  • Menu → Bookmarks: View saved bookmarks / tap to jump to position

Viewer Settings (Menu → Viewer Settings)

  • Page Turn Mode:
    • Scroll: Free scroll, use bottom buttons for chapter navigation
    • Tap Left/Right: Tap left or right side of screen to change chapter
    • Tap Top/Bottom: Tap top or bottom of screen to change chapter
    • Swipe Left/Right: Swipe horizontally to change chapter
    • Swipe Up/Down: Swipe vertically to change chapter
  • Reverse Direction: Swap the prev/next direction
  • Font Size: Adjust with slider (12–44px)
  • Prevent Image Clipping: Keep images within screen bounds
  • Background Color / Text Color: Choose from color palette

Image Gallery

  • Menu → Image Gallery: Shows all images in the book
  • Tap an image: Navigate to the chapter containing it
💡 Tip: In Tap Left/Right mode, tapping the center of the screen does nothing — useful for checking details without accidentally flipping chapters.
