# 음악 이름 관리 (시안 단계)

mp3 파일의 **이름을 목록으로 관리**하고 **텍스트로 추출**하는 앱. 음악 재생 기능은 없다. 지금은 **디자인 시안만** 있고 기능은 없다.

- 시안: https://kjooy0305.github.io/i_make_a_app/musiclist/mock/ (`#home` `#up` `#dup` `#txt` `#all` 로 화면 바로 열기)
- 형식은 `dayclean/mock` 과 같다. 화면 고르는 줄 + 폰 비율(390×844) 한 대 / 전체 보기.

## 화면 (시안 안에서 눌러볼 수 있다)
1. **목록(홈)** — 곡 이름·가수·용량, 검색(입력하면 바로 걸러짐), 정렬(최근 추가 / 제목순 / 가수순), `이름 복사` · `목록 txt 추출` · `＋ 추가`. 목록은 스크롤되고, 아래에 더 있으면 하단 페이드와 스크롤바가 보인다.
2. **음악 업로드** — `파일 선택`(예시 5개 불러오기), 파일별 표시(새 파일 / 같은 이름 / 비슷한 이름), `비우기`, `업로드 시작`
3. **같은 이름** — 기존 파일과 새 파일을 비교해 `따로 저장`((1) 붙임) / `덮어쓰기` / `지우기`(새 파일 버림) 중 선택. `남은 파일도 같은 방식으로 처리` 체크.
4. **비슷한 이름** — (1)을 붙이지 않는다. "이 파일은 다른 음악인가요?"를 먼저 묻는다.
   - `다른 음악이에요` → **비슷한 노래 묶음**으로 묶어 보관 (이름은 그대로)
   - `같은 음악이에요 · 덮어쓰기` / `같은 음악이에요 · 지우기`
5. **비슷한 노래 묶음** — 홈 목록에서 "○○ 계열 N곡"으로 한 줄에 접혀 있고, 탭하면 펼쳐진다. 검색 중에는 자동으로 펼쳐진다.
6. **텍스트 추출 시트** — 형식(이름만 / 가수 - 이름 / 확장자 포함)을 고르면 미리보기가 바뀐다. 묶음은 나란히 적힌다. `이름 복사` / `txt 파일로 저장`

## 결정 사항
- 음악 재생·가사 추출 기능은 넣지 않는다. 이름 관리와 텍스트 추출만 한다.
- 시안은 정적 화면이 아니라 dayclean 시안처럼 간단한 상호작용과 스크롤이 동작해야 한다. 실제 파일 저장·복사만 빠진다.
- 안드로이드 앱으로 만들 때는 이 시안의 화면과 문구를 그대로 따른다.
