# 음악 이름 관리 (시안 단계)

mp3 파일의 **이름을 목록으로 관리**하고 **텍스트로 추출**하는 앱. 음악 재생 기능은 없다. 지금은 **디자인 시안만** 있고 기능은 없다.

- 시안: https://kjooy0305.github.io/i_make_a_app/musiclist/mock/ (`#home` `#up` `#dup` `#txt` `#all` 로 화면 바로 열기)
- 형식은 `dayclean/mock` 과 같다. 화면 고르는 줄 + 폰 비율(390×844) 한 대 / 전체 보기.

## 화면
1. **목록(홈)** — 곡 이름·가수·용량, 검색, 정렬(최근 추가 / 제목순 / 가수순), `이름 복사` · `목록 txt 추출` · `＋ 추가`
2. **음악 업로드** — 파일 선택/끌어놓기, 선택한 파일 목록(새 파일 / 같은 이름 / 비슷한 이름 표시), 업로드 시작
4. **텍스트 추출 시트** — 형식(이름만 / 가수 - 이름 / 확장자 포함)을 고르고 미리보기 확인 후 `이름 복사` 또는 `txt 파일로 저장`
3. **같은 이름 선택 시트** — 기존 파일과 새 파일을 나란히 비교하고 한 가지를 고른다.
   - **따로 저장**: 이름 뒤에 `(1)`을 붙여 둘 다 보관
   - **덮어쓰기**: 기존 파일을 새 파일로 교체
   - **지우기**: 새 파일은 올리지 않고 버림 (기존 파일 유지)
   - `남은 파일도 같은 방식으로 처리` 체크, 취소 / 확인

## 결정 사항
- 시안의 모든 버튼은 동작하지 않는다.
- 음악 재생·가사 추출 기능은 넣지 않는다. 이름 관리와 텍스트 추출만 한다.
- 안드로이드 앱으로 만들 때는 이 시안의 화면과 문구를 그대로 따른다.

## 열린 질문
- "지우기"의 뜻: 새 파일 버리기(현재 시안) vs 기존 파일 삭제 후 새 파일 추가.
