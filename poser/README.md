# 포저 (시안 단계)

3D 마네킹으로 포즈를 잡고 캡처하는 앱. 사이트로 기반을 다진 뒤 안드로이드 앱으로 만든다.

- 시안: https://kjooy0305.github.io/i_make_a_app/poser/mock/ (`#work` `#add` `#pose` `#hand` `#cam` `#light` `#save` `#set` `#menu`)
- 분석: [docs/analysis.md](docs/analysis.md) — easypose_1.7.8.apks 분석 (구조, 모델 만드는 과정, 관절, 수익 구조)

## 시안에서 움직이는 것
- 몸: 원본의 71개 관절 구조와 몸 비율(관절 위치, 부위별 단면 크기)을 참고해 **직접 만든 형태**로 구현. 모델 10종 (남·여 일반, 남·여 소형, 남·여 4등신, 히어로 남·여, 빅맨, 운동소년)
- 관절(노란 점) 선택 → X/Y/Z 슬라이더, 보조 관절(Twist), 좌우 대칭, 관절 잠금, 초기값, 몸중심 높이, 눈동자 방향
- 손: 핸드포즈 6종, 손가락 편집(손가락 5개 × 좌우 회전·관절 1~3)
- 완성된 포즈 25개 (일반·앉기·다이나믹·특수), 소품 12종, 헤어 9종 + 색, 의상 5종 + 상·하의 색, 피부 색
- 모델 추가·복사·삭제·변경, 되돌리기/다시, 카메라(좌·정·우, 화각, 격자, 프리셋), 조명, 캡처 미리보기, 저장 슬롯 5개
- 화면만 있음: 동물·탈것 팩, 상점, 설정 일부

## 참고 자료 사용 범위
- `mock/body-data.js` 에는 원본에서 읽은 **숫자(관절 위치, 단면 크기)** 만 들어 있다. 원본의 메시·텍스처·애니메이션은 이 저장소에 없다.

## 내 모델 팩 (개인용)
- 원본 앱에서 읽은 모델(몸 48종, 헤어 62, 신발 80, 소품 139, 텍스처 72)은 `poser-models.pack` 한 파일로 만들었고, **저장소에는 올리지 않는다.** 개인 작업 폴더(`poser_private/`)에만 있다.
- 시안에서 `메인 메뉴 › 내 모델 팩 › 팩 파일 선택`으로 불러오면 그 기기의 브라우저(IndexedDB)에만 저장된다. 팩이 없으면 기본 마네킹이 나온다.
- 팩을 만든 스크립트와 읽는 방법은 분석 문서(`docs/analysis.md`) 10번에 있다.
