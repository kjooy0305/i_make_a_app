# Stick Fighter

스틱맨 애니메이션 만들기. 7.1.1 APK의 기능을 참고해 처음부터 새로 만든 앱입니다.

## 기능

- 키 프레임마다 피규어 자세를 잡으면 사이 장면을 자동으로 이어 줍니다.
- 화면 전체가 편집 영역입니다. 두 손가락으로 확대·축소, 빈 곳을 끌어 이동하고, 도구 막대는 숨길 수 있습니다.
- 이전 장면이 회색 밑그림으로 깔려 자세를 이어 잡기 쉽습니다(끌 수 있음).
- 장면 창(프레임 목록)과 미리보기 창(장면 전환·전체 반복 재생)은 필요할 때 띄웁니다. 미리보기 창은 편집 중에도 계속 반영됩니다.
- 조작: 파란 점으로 이동, 빨간 점으로 자세 잡기, 주황 점으로 늘이기, 청록 점으로 색·굵기, 보라 점으로 좌우 반전
- 기본 피규어 6종과, 부품(선·원)을 붙여 만드는 내 피규어
- 재생(속도 조절, 반복), MP4 영상 저장, 백업(.sfa) 저장과 가져오기, 공유
- 저장소 권한과 인터넷 권한이 필요 없습니다.

## 구조

| 폴더 | 내용 |
|---|---|
| `model/` | 피규어·프레임·애니메이션, 관절 계산(`Kinematics`), 편집(`FigureEdit`), 보간(`Interpolator`), 기본 피규어(`Templates`) |
| `data/` | JSON 저장(`Json`, `Repository`), .sfa 백업(`Sfa`) |
| `render/` | 한 장면 그리기(밑그림 포함), 확대·이동 계산(`ViewTransform`). 편집기·썸네일·재생·영상이 같은 그리기를 씁니다. |
| `video/` | MediaCodec으로 MP4 인코딩 |
| `ui/` | 홈, 편집기, 재생 화면 |

## 테스트

```
./gradlew testDebugUnitTest
```

`EngineTest`는 모델·보간·저장을, `UiSmokeTest`(Robolectric)는 화면이 열리고 점을 끌어 고쳐지는지를 확인합니다.
영상 저장(MediaCodec)은 실제 기기에서만 확인할 수 있습니다.

## 7.x(옛 버전)와의 차이

옛 .sfa 파일(XML 기반)은 읽지 못합니다. 8.0.0의 .sfa는 JSON을 담은 zip입니다.
