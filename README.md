## 📜 스크립트 TRPG 작성 앱 (make123)

> **설치 가능 기기:** Android 스마트폰 · 태블릿 (Android 8.0 이상)
> **파일 형식:** `.apk`

TRPG(테이블탑 롤플레잉 게임) 시나리오를 직접 쓰고, 그 자리에서 플레이할 수 있는 올인원 앱입니다.

### 기능
- **씬 카드 에디터** — `#1#`, `#2#` 번호 단락으로 씬을 작성하고 선택지를 연결
- **플레이어 뷰** — 씬 이동, 조건부 선택지 잠금, 플래그·아이템 시스템, 트리거(HP≤0 → 즉사 씬)
- **캐릭터 시트** — 능력치(STR/DEX/CON 등) 자유 추가·삭제, HP/SAN/MP 바, 신체 부위 10개 피해 단계, 초상화 업로드
- **주사위 패널** — d4 / d6 / d8 / d10 / d12 / d20 / d100
- **내장 시나리오: 독스프** — 크툴루 TRPG 밀실 탈출 시나리오 (~71씬, 트리거·플래그 완비)
- **솔로 플레이** — 8명 캐릭터 중 3명과 진행, 호감도 시스템, 히든 루트, 4가지 엔딩
- **씬 흐름 그래프** — BFS 레이어 배치 SVG 그래프로 시나리오 구조 시각화
- 오프라인 완전 동작 / 데이터 앱 내 영구 저장

### 설치 방법
1. [Releases](../../releases?q=make123)에서 `TRPG-make123-vX.X.X.apk` 다운로드
2. 안드로이드 → **설정 > 보안 > 알 수 없는 앱 허용** 활성화
3. APK 파일 실행 후 설치

> 크롬 브라우저 기록·캐시를 지워도 앱 데이터는 사라지지 않습니다.

## 🔎 소설 키워드 분석기 (KeywordScan)

> **설치 가능 기기:** Android 스마트폰 · 태블릿 (Android 8.0 이상)
> **파일 형식:** `.apk`

TXT · ePub 소설 파일을 읽어 등록한 키워드가 얼마나 등장하는지 자동으로 세고, 그 결과로 검색·태그 파일명 생성까지 해주는 분석 앱입니다.

### 기능
- **다중 키워드 1회 스캔** — 수십 개 키워드를 본문 한 번 훑으면서 동시에 집계 (유의어는 한 키워드로 합산, 띄어쓰기 무시)
- **빈도 · 밀도 · 분포** — 등장 횟수, 1만자당 빈도, 소설 10개 구간별 분포(분산 / 집중)
- **상위 / 하위 키워드** — 상위는 검색·목록에 보여줄 대표 단어, 하위는 본문에서 실제로 찾는 세부 요소
- **키워드 관리** — 추가 · 수정 · 삭제, 키워드 변경 후 기존 파일 재분석 (필요한 것만 / 전체)
- **파일명 태그 `(!)` / `(?)`** — 키워드별 임계 횟수 이상이면 `(!)`, 있지만 미달이면 `(?)` (예: `작품명_무협(!)_로맨스판타지(?)`). 앱이 만든 이름을 복사해서 파일명에 쓰세요
- **유사 파일명 중복 경고** — 제목 일부·뒷부분만 비슷해도 경고 → 덮어쓰기 / 이름 변경 후 추가 / 취소
- **검색** — 상위 키워드로만 필터(하나라도 / 모두), 결과마다 하위 키워드 목록 표시
- **호감 · 일반 · 불호** 영역 구분 표시, 불호 키워드(!) 포함 소설 제외 옵션
- **목록 txt 추출** — 현재 검색 결과를 `제목 | 상위태그` 형식의 텍스트 파일로 저장
- **대량 업로드** — 100개 이상 한 번에 선택, 한 파일씩 순차 처리하는 대기열
- 오프라인 완전 동작 / IndexedDB 영구 저장

### 설치 방법
1. [Releases](../../releases?q=keywordscan)에서 `KeywordScan-vX.X.X.apk` 다운로드
2. 안드로이드 → **설정 > 보안 > 알 수 없는 앱 허용** 활성화
3. APK 파일 실행 후 설치

## ⌨️ ShortKey

> **설치 가능 기기:** Windows 10 · 11 PC
> **파일 형식:** `.exe` (단일 실행 파일, 설치 불필요)

지정한 단축키를 누르면 미리 설정한 앱을 바로 실행해주는 백그라운드 유틸리티입니다.

### 기능
- **전역 단축키** — Ctrl+Alt+N 등 키 조합을 자유롭게 설정
- **다양한 앱 지원** — `.exe`, `.lnk`(바로가기), UWP 앱, `ms-settings:` URI, 메모장·계산기 등 윈도우 내장 앱 전부 가능
- **항상 최전면** — 단축키로 실행한 앱이 모든 창 앞으로 올라옴
- **중복 실행 방지** — 이미 실행 중이면 설정 창만 앞으로
- **시스템 트레이 상주** — 백그라운드 실행 중 트레이 아이콘으로 확인
- **완전 종료 버튼** — 설정 창에서 즉시 프로세스 종료 가능

### 설치 방법
1. [Releases](../../releases?q=shortkey)에서 `ShortKey-vX.X.X.exe` 다운로드
2. 파일 실행 (설치 과정 없음)
3. 트레이 아이콘 클릭 → 설정 창에서 단축키 + 앱 경로 등록

## 📖 나만의 이야기 에디터 (StoryEditor) — 웹 버전

> `storyeditor/web/index.html` 을 브라우저로 열면 바로 동작합니다. (Android 앱은 추후 제작 예정)

페이지 + 선택지로 이어지는 분기형 텍스트 게임을 혼자 쓰고 바로 플레이해 보는 에디터입니다.

### 기능
- **프로젝트** — 만들기 / 설정(이름·태그·커버 색·상태값) / 복제 / 삭제 / JSON 내보내기·가져오기
- **페이지** — 본문 1000자 제한, 마지막 페이지 지정, 복제·삭제, 번호·본문 검색
- **폴더** — 메인 / 서브 / 랜덤 이벤트 탭으로 페이지를 나눠 관리 (번호는 전체에서 이어지고 폴더가 달라도 선택지로 자유롭게 연결)
- **선택지** — 위아래 이동, 복제·삭제, 이동할 페이지(기본값: 마지막 페이지+1)
- **조건** — 노출 조건(없으면 숨김) / 활성 조건(없으면 비활성). `열쇠, 지도*2, !뱀, 돈>=100` 형식
- **속성** — 얻는·잃는 아이템(`아이템*수량`, `@히든`), 업적 달성, 상태값(체력·멘탈·돈 등) 변화
- **분기** — 확률 기준(합 100%, 나머지는 기본 설정) / 보유 아이템 기준(위에서부터 차례로 판정)
- **분기도 (ReactFlow)** — 이전 이야기(회색) → 선택한 이야기(굵은 테두리) → 도착 페이지(클릭 버튼) 3열 페이지 단위 화면. 같은 페이지로 모이는 선택지는 한 노드에 합쳐 표시. 휠·핀치·구석 버튼으로 확대/축소, ✎로 선택지 수정, ＋로 새 분기·새 페이지를 이어 붙임
- **스토리 JSON** — `[{ id, title, text, choices:[{ text, to }], end }]` 배열로 한 번에 보기·추가·수정
- **업적**, **미리보기**(저장 안 됨, 특정 페이지부터 시작 가능), **검사**(빈 본문·끊긴 링크·확률 초과 등)
- 사용 라이브러리(`web/vendor/`에 포함, 오프라인 동작): React 18.3.1, ReactFlow 11.11.4
