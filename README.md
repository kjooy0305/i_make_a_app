## 📜 스크립트 TRPG 작성 앱 (make123)

> **설치 가능 기기:** Android 스마트폰 · 태블릿 (Android 8.0 이상)
> **파일 형식:** `.apk`

TRPG(테이블탑 롤플레잉 게임) 시나리오를 직접 쓰고, 그 자리에서 플레이할 수 있는 올인원 앱입니다.

### 기능
- **씬 카드 에디터** — `#1#`, `#2#` 번호 단락으로 씬을 작성하고 선택지를 연결
- **플레이어 뷰** — 씬 이동, 조건부 선택지 잠금, 플래그·아이템 시스템, 트리거(HP≤0 → 즉사 씬)
- **캐릭터 시트** — 능력치(STR/DEX/CON 등) 자유 추가·삭제, HP/SAN/MP 바, 신체 부위 10개 피해 단계, 초상화 업로드
- **주사위 패널** — d4 / d6 / d8 / d10 / d12 / d20 / d100
- **내장 시나리오: 독스프** — 크툴루 TRPG 밀실 탈출 시나리오 (~71씬, 트리거·플래그 완비)
- **솔로 플레이** — 8명 캐릭터 중 3명과 진행, 호감도 시스템, 히든 루트, 4가지 엔딩
- **씬 흐름 그래프** — BFS 레이어 배치 SVG 그래프로 시나리오 구조 시각화
- 오프라인 완전 동작 / 데이터 앱 내 영구 저장

### 설치 방법
1. [Releases](../../releases?q=make123)에서 `TRPG-make123-vX.X.X.apk` 다운로드
2. 안드로이드 → **설정 > 보안 > 알 수 없는 앱 허용** 활성화
3. APK 파일 실행 후 설치

> 크롬 브라우저 기록·캐시를 지워도 앱 데이터는 사라지지 않습니다.

## ⌨️ ShortKey

> **설치 가능 기기:** Windows 10 · 11 PC
> **파일 형식:** `.exe` (단일 실행 파일, 설치 불필요)

지정한 단축키를 누르면 미리 설정한 앱을 바로 실행해주는 백그라운드 유틸리티입니다.

### 기능
- **전역 단축키** — Ctrl+Alt+N 등 키 조합을 자유롭게 설정
- **다양한 앱 지원** — `.exe`, `.lnk`(바로가기), UWP 앱, `ms-settings:` URI, 메모장·계산기 등 윈도우 내장 앱 전부 가능
- **항상 최전면** — 단축키로 실행한 앱이 모든 창 앞으로 올라옴
- **중복 실행 방지** — 이미 실행 중이면 설정 창만 앞으로
- **시스템 트레이 상주** — 백그라운드 실행 중 트레이 아이콘으로 확인
- **완전 종료 버튼** — 설정 창에서 즉시 프로세스 종료 가능

### 설치 방법
1. [Releases](../../releases?q=shortkey)에서 `ShortKey-vX.X.X.exe` 다운로드
2. 파일 실행 (설치 과정 없음)
3. 트레이 아이콘 클릭 → 설정 창에서 단축키 + 앱 경로 등록
